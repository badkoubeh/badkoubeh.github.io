Projects

Open measurement tools you install and run yourself — not a service, not a leaderboard.

marginkit

The measurement primitive

Model-agnostic dose-response threshold estimation. Feed it (severity, outcome) observations; get back σ* with a confidence interval, right-censoring handled, and Fieller intervals for comparing two failure modes. No GPU, no ML dependency.

marginbenchIn development

The harness

Degradation axes calibrated against named IMU and GNSS datasheets, model adapters behind a single interface, and an auto-generated robustness report card — in metres, degrees, and milliseconds.

zeta-bench

Where it started

A reproducible robustness benchmark for control systems: stress-testing RL, MPC, LQR, world-model, and PID controllers across a physics-grounded disturbance matrix, including a PID controller on a 6-DOF rocket. marginkit is being extracted from it.
